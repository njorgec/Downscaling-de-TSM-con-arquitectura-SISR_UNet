# Downscaling de TSM con arquitectura SISR-UNet

Este repositorio contiene el código fuente modular para el entrenamiento de una red neuronal de super-resolución (SISR-UNet) aplicada al downscaling de Temperaturas Superficiales del Mar (TSM).

## Estructura del proyecto
Todo el código fuente se encuentra dentro de la carpeta `SISR_UNet/`:
- `config.py`: Rutas e hiperparámetros.
- `data_utils.py`: Carga y normalización de datos `.npy`.
- `model.py`: Arquitectura U-Net.
- `train.py`: Script principal de entrenamiento.
- `requirements.txt`: Dependencias del proyecto.

## Uso
Por favor, dirígete a la carpeta `SISR_UNet/` para leer las instrucciones detalladas de ejecución.
